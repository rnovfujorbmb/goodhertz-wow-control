## Overview

Goodhertz Wow Control adds pitch instability, wow, and flutter artifacts to any audio signal, simulating the mechanical imperfections of tape machines and turntables for vintage atmosphere.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Goodhertz Wow Control** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Wow Engine** | Low-frequency pitch modulation matching tape transport mechanics |
| **Flutter Engine** | Higher-frequency pitch instability modeling motor vibration |
| **Crinkle Mode** | Random pitch artifacts simulating worn or damaged tape |
| **Sync** | Modulation rates lockable to BPM for rhythmic pitch fluctuation |
